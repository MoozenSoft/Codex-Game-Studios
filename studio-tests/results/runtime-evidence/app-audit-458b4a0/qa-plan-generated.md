## Manual QA Checklist

**方法**：通过专用 fixture 的已确认接口逐步执行并读取计数。\
**输入约定**：L 为已确认合法事件，I 为已确认非法事件；同一序列重放时，事件内容及顺序保持一致。每个用例使用独立状态，从 0 开始。\
**签核角色**：qa-lead 或用户指定审阅者；本回合不委派。\
**证据**：具体输入、初始值、每步实际计数、预期值、执行回执、判定与审阅结论。

| ID | 对应条件 | 操作 | 预期结果 |
|---|---|---|---|
| QA902-01 | AC1 | 初始化，不发送事件 | 计数为 0 |
| QA902-02 | AC1 | 初始化后发送 L | 计数由 0 变为 1 |
| QA902-03 | AC1 | 顺序发送 L、L、L | 每步计数为 1、2、3 |
| QA902-04 | AC1 | 初始化后发送 I、I | 每步计数均为 0 |
| QA902-05 | AC1 | 顺序发送 L、I、L、I | 每步计数为 1、1、2、2；非法事件在非零状态下也不改变计数 |
| QA902-06 | AC2 | 两份独立的相同初始状态，重放完全相同的 L、I、L、I 序列 | 两次每步计数一致，最终均为 2 |
| QA902-07 | AC1、AC2 | 两份独立的相同初始状态，各执行空事件序列 | 两次计数均为 0 |
