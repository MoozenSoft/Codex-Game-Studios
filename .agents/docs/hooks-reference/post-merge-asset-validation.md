# 合并后的资产复核

此流程由调用者显式执行，没有注册自动 post-merge hook。合并到主干或 release 分支且涉及资产时，使用 `$asset-audit` 检查命名、尺寸、格式、引用和预算。

确定范围时使用明确的合并前后提交，并以 NUL 分隔读取 Git 文件列表，避免空格或中文路径被拆开。资产根与命名约定按当前引擎选择，不能把 Godot 的小写下划线规则强加给 Unity 或 Unreal。

测量实现为 `.agents/scripts/asset-scan.sh`；用 `--help` 查看实际参数。体积预算来自 Art Bible 或当前任务的明确要求，例如项目明确规定的纹理 4 MiB、音效 512 KiB；不把示例预算当成所有游戏的强制默认值。无法检查的格式、音频元数据或二进制编辑器资产明确标记未评估。

命名问题交 art-director 判断，优化问题交 technical-artist；当前任务缺少必要的资产验证证据时不关闭相应发布门禁。测量结果与领域裁决分别保留，不以“合并已完成”代替资产验收。
