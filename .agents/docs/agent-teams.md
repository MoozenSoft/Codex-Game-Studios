# Codex 团队工作流

团队 Skills 在同一个 Codex 任务中委派专业子代理，按 `team.size` 选择实际参与者。
individual、small、studio 表示领域参与范围，并非独立权限等级；角色定义与运行约定见 coordination-rules.md。
不维护上游多客户端独立会话团队接口，也不假定共享 TaskCreate 列表存在。

有独立输入和互不重叠输出的任务可并发；共享文件、后续依赖和跨领域决策串行处理。
并发额度不足时排队或串行；没有子代理工具时披露降级执行方式，必要的独立评审不能伪报完成。
每次团队执行保留任务简报、实际角色集合、产物、证据和未评估项。
