# Codex 工作树与个人配置

工作目录由当前 checkout 决定，先核对 `git worktree list`、当前分支与 Git common dir。
优先使用目标 Codex 客户端提供的工作树入口；手工 Git 工作树必须位于已核对的工作区目录，避免在已隔离 checkout 内重复创建工作树。

上游 `.worktreeinclude` 不是 Codex 的运行配置，不假定 Codex 自动复制该文件中的路径。
新工作树需要个人配置时，先检查目标是否已经存在，再仅复制用户已批准共享的 `project.local.yaml`；不覆盖已有文件，不复制凭据、.env、客户端账号文件或旧客户端权限配置。

新工作树默认只包含已提交内容。开始任务前报告必要但未提交的输入，不能声称工作树已经包含这些改动。
任务返回时记录分支、产物、测试证据与未评估项；合并和推送遵守当前会话授权。
